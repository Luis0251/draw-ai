# DrawFlow AI - Editor de Diagramas con IA

![Static Badge](https://img.shields.io/badge/status-active-success)
![Static Badge](https://img.shields.io/badge/license-MIT-blue)
![Static Badge](https://img.shields.io/badge/version-1.0.0-orange)

**DrawFlow AI** es un editor de diagramas interactivo potenciado por inteligencia artificial que permite crear flujos visuales conectando nodos inteligentes.

## 🚀 Características principales

- **Editor visual interactivo** basado en tldraw
- **Nodos inteligentes**:
  - 📝 Nodos de texto con editor enriquecido (TipTap)
  - 🖼️ Nodos de imagen generados por IA
- **Conexiones automatizadas** entre nodos
- **Generación de contenido** mediante IA:
  - Respuestas de texto automáticas
  - Generación de imágenes desde prompts
- **Atajos de teclado** para todas las herramientas
- **Sistema de bloqueo** de formas

## 📦 Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/Luis0251/drawflow-ai.git
cd drawflow-ai
```
2. Instalar Dependencias
```bash
npm install
# o
yarn install
```
3. Configurar variables de entorno:
```bash
cp .env.example .env.local
```
## 🎮 Uso básico

### Herramientas disponibles

| Atajo | Herramienta | Descripción |
|-------|------------|-------------|
| `S`   | Selección  | Seleccionar y mover elementos |
| `T`   | Texto      | Añadir nodos de texto |
| `A`   | Flecha     | Conectar nodos |
| `I`   | Input      | Nodos de entrada con IA |
| `M`   | Imagen     | Generar imágenes con IA |
| `D`   | Dibujo     | Dibujo libre |
| `E`   | Borrador   | Eliminar elementos |
| `G`   | Formas     | Insertar formas geométricas |
